# Predicting Student Course Completion Using Machine Learning

## Overview

This project develops a machine learning model to predict whether learners will complete or drop an online course.

## Dataset

- Source: Kaggle
- 4,000 learner records
- 25 variables

## Algorithms

- Logistic Regression
- Decision Tree
- Random Forest
- XGBoost
- Support Vector Machine

## Results

The Tuned Support Vector Machine achieved the highest Recall and ROC-AUC, making it the preferred model for identifying at-risk learners.
